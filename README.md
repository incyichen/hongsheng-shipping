# 泓昇海鮮 出貨對帳系統

取代 Excel 出貨單／對帳單的單機程式，Rust（Tauri 2）＋ SQLite，編譯成一個 Windows exe。

## 功能

- **出貨單**：選客戶自動帶出電話、地址、稅別；品項打代號或名稱，單價依序帶入「客戶專屬價 → 此客戶上次成交價 → 品項預設價」；秤重品項可輸入「2斤5兩」；可從同客戶舊單複製品項；草稿／存檔／列印
- **退貨／折讓單**：金額自動為負，從應收扣除
- **對帳單（手開）**：獨立作業的對帳單，選客戶後只輸入「日期＋金額＋備註」，不連品項、不算進客戶未收金額。標題印成「10月份對帳單」，單號 M年月-流水號。日期只要打「28」就會變成對帳月份的 28 日（也接受 10/28、完整日期或民國年），同一天重複或不在對帳月份會提醒；存檔時依日期排序。列印可選「左右兩欄」（一張中一刀 28 天）或「單欄」（一張 14 天），每張單可以自己切換，預設值在設定頁
- **對帳單**：依客戶結帳日（月底或每月某日）算期間，自動撈出已開立的出貨單，前期未收＋本期－收款＝本期應收；可選「每張單一列」或「展開品項」；建立後出貨單鎖定，作廢對帳單即解鎖
- **收款**：登錄收款，客戶清單直接顯示未收金額
- **品項、客戶**：停用而不刪除，舊單據的品名、單價、客戶資料都是存檔當下的快照，不受之後修改影響
- **中一刀連續報表**：每一張都是中一刀（半張），筆數多就接著印下一張。第一張有標題、客戶資料和欄位名稱，之後的張數直接接著印明細，不重印欄位名稱、不印頁碼，最後一張接合計與簽名；不撕開就是一份連續的單據。1～14 筆 1 張、15～43 筆 2 張、44～72 筆 3 張。出貨單、對帳單都適用。設定頁可改成「放得下印半張、否則整張」或「一律整張」，也可以取消「連續報表」改回每張重印欄位名稱與頁碼
- **列印**：多頁時標題與客戶資料只在第一頁、合計與簽名只在最後一頁且不會被拆開，每頁頁尾有單號、客戶、頁次
- **備份**：每天第一次開程式自動備份（保留 30 份），可另外指定雲端同步資料夾

## 客戶、品項欄位的選法

點進客戶或品項欄位就會列出全部（目前選的會標示「目前」），原本的字會自動全選，直接打字就是重新搜尋。客戶可以用名稱、代號、電話搜尋，品項可以用名稱、代號搜尋。用 ↑↓ 選擇、Enter 確定、Esc 關閉，也可以用滑鼠點。出貨單選好品項後游標會直接跳到數量。

## 開單時新增品項

出貨單的品名可以直接打清單裡沒有的名稱，選單會出現「＋ 新增品項」。存檔（含草稿）時，這些品名會連同單位、單價自動加入品項清單：代號留空，單價空白或 0 的會存成時價，單位是斤、兩的會自動設成秤重。之後到「品項」補代號或改售價即可。已經有同名品項的會直接連過去，不會重複新增。

## 刪除客戶、品項

在客戶或品項頁點選一筆，表單下方有「刪除」。沒用過的直接刪除；已經有出貨單（客戶還包括收款、對帳單）的會改成「停用」：不再出現在開單選單，舊單據和帳款不受影響。勾選「顯示停用」可以看到停用的項目，取消勾選「使用中」再儲存即可恢復。

## 關閉視窗＝縮到右下角

按視窗右上角的 ✕ 不會結束程式，會縮到工作列右下角繼續提供手機同步。再點一次 exe 或左鍵點右下角圖示，就會叫出原本的視窗（不會開第二個）。要真正結束：對右下角圖示按右鍵 →「結束程式」。

## 新增客戶、品項

新增完一筆會自動清空表單，可以直接輸入下一筆。在清單點一筆就是「編輯」該筆，表單標題會寫「編輯客戶：名稱」、按鈕變成「儲存修改」；要回到新增，按「改為新增」。

## 手機同步（電腦端）

電腦是唯一的正式資料庫，出貨系統開著時會在背景提供「同步服務」（預設連接埠 47110，可在「設定 → 手機同步」關閉或更改）。手機透過 Tailscale（外出時）或同一個 Wi-Fi（在現場時）連到這台電腦。

**同步規則**

| 資料 | 方向 |
|---|---|
| 客戶 | 雙向（手機可以新增、修改；同時修改以電腦為準） |
| 品項、客戶專屬價、上次成交價 | 電腦 → 手機 |
| 出貨單草稿 | 雙向，全部同步 |
| 已開立的出貨單 | 雙向：手機開的 → 電腦；電腦上最近 60 天的 → 手機（核對、修改、列印給客戶） |
| 出貨（列印給客戶）的時間 | 手機 → 電腦 |

- 手機開的單號字頭是 `V1-`（第二台 `V2-`），不會跟電腦的 `S` 單號重複；停用的手機字頭不再使用
- 手機新增的客戶在「客戶」頁標示「待確認」，可以確認無誤，或合併到既有客戶（名稱或電話相同會提示可能重複）。合併後出貨單、收款、對帳單都會移過去
- 同一張單兩邊都改過：手機已開立（客戶手上已有單）以手機為準，電腦的修改另存；兩邊都是草稿以電腦為準，手機的版本另存，可以在「出貨單」頁上方的提醒裡選擇改用
- 已列入對帳單的單，手機的修改不會套用；手機很晚才上傳、日期落在已建立對帳單期間內的單，也會提醒
- 存草稿可以先不填單價（時價品項採購後再補），開立時每一項都要有單價

**配對手機**：設定 → 手機同步 →「新增手機」，在手機 App 輸入畫面上的電腦位址和 6 位數配對碼（10 分鐘內有效、只能用一次）。手機遺失或換機時，在同一個地方按「停用」。

## 手機 App（一般 Android 手機＋Zebra ZR328）

**安裝**：到 GitHub 專案的 Actions → 最新一次 build → Artifacts 下載 `hongsheng-handheld-apk`，解壓後把 `.apk` 傳到手機安裝（第一次要允許「安裝不明來源的應用程式」），或用 `adb install -r 檔名.apk`。之後的新版直接覆蓋安裝，資料會保留。**不要先移除舊版**，移除會清掉手機上還沒上傳的單。

**第一次使用**：手機連上 Tailscale（在店裡同一個 Wi-Fi 也可以）→ 打開「泓昇出貨」→ 輸入電腦的位址（例如 `100.101.102.103`，連接埠不用打）和電腦上產生的 6 位數配對碼 → 自動下載客戶、品項和出貨單。

**下方工具列**：出貨單｜客戶

**出貨單**
- 分成「待出貨」和「已出貨」。待出貨＝草稿＋已開立但還沒列印給客戶的單（包含在電腦上開好的單）
- 打開一張單核對品項；有錯可以點品項修改，按「儲存並列印」會更新電腦上的單並印出
- 沒問題按「列印出貨單」給客戶簽收。**列印就算出貨**：單會移到「已出貨」，電腦的出貨單清單也會顯示「已出貨 時間」。之後再印會標示「補印」
- 草稿缺單價的品項是橘色框，填好單價後按「開立並列印」
- 「＋ 開新出貨單」→ 選客戶（也可以直接新增）→ 加品項 → 填數量、單價。數量可以打 `3`、`2.5`、`2斤5兩`
- 單價自動帶入：客戶專屬價 → 這個客戶上次的成交價 → 品項預設價；時價品項自己輸入
- 清單沒有的品名直接打，會自動加入品項清單
- 已列入對帳單的單只能補印；電腦上已有的已開立單不能在手機刪除

**客戶**：搜尋、看電話地址（可以直接撥打）、新增、修改名稱／電話／地址／稅別／統編／備註。代號、結帳日在電腦上改。手機和電腦同時改了同一個客戶時，以電腦為準。

**印表機（Zebra ZR328，80mm 熱感紙）**：先在手機的「設定 → 藍牙」配對印表機（PIN 通常是 0000 或 1234）。App 的「設定」：
- 印表機：維持「自動」就會使用已配對的藍牙印表機；配對了好幾台藍牙裝置時，直接選 ZR328
- 紙張寬度：80mm（576 點）或 58mm（384 點）
- 印表機指令：先用 ESC/POS 按「列印測試單」；印出亂碼或一堆符號就改選 CPCL（斑馬行動印表機的指令）再試

**熱感單內容**：公司名稱、單號、日期、客戶、每項「數量 × 單價 ＝ 金額」、依客戶稅別顯示稅金（外加：小計／稅金／總金額；內含：總金額＋含稅金；免稅）、簽收欄。

**離線**：沒網路照樣開單、列印，資料存在手機上。網路恢復、App 打開或回到前景、每 2 分鐘都會自動同步。App 完全關掉時不會同步，下次打開會補上。手機只保留最近 60 天的已開立單，電腦上永遠都在。

## Tailscale 設定（電腦和手機連線）

1. 電腦和手機都安裝 Tailscale，用**同一個帳號**登入。生意用途要用 Tailscale 的付費方案（免費方案限非商業使用）
2. 電腦：右鍵點工作列的 Tailscale 圖示 → Preferences → 勾選 **Run unattended**，Windows 沒登入也保持連線
3. Tailscale 管理後台（login.tailscale.com）→ Machines → 電腦和手機各自的「…」→ **Disable key expiry**，否則大約半年要重新登入
4. 手機：Android 設定 → 網路 → VPN → Tailscale 旁的齒輪 → 開啟「**永久連線的 VPN**」
5. 第一次開新版出貨系統時，Windows 防火牆會詢問是否允許網路存取，請**允許**。如果手機透過 Tailscale 連不到，用系統管理員身分開啟 PowerShell 執行下面這行，只開放 Tailscale 和區域網路連進來：
   ```
   New-NetFirewallRule -DisplayName "泓昇出貨系統同步" -Direction Inbound -Protocol TCP -LocalPort 47110 -RemoteAddress 100.64.0.0/10,LocalSubnet -Action Allow
   ```

**先測試連線（手機 App 完成前就能測）**：手機裝好 Tailscale 並連線後，用手機瀏覽器打開「設定 → 手機同步」裡 Tailscale 那一個位址，後面加 `/api/ping`，例如 `http://100.101.102.103:47110/api/ping`。看到一段包含公司名稱的文字，就代表連線和防火牆都設定好了。

## 下載編譯好的程式（不用自己編譯）

程式放上 GitHub 後會自動編譯：專案頁面 → Actions → 最新一次 build → 最下方 Artifacts：

- `hongsheng-shipping-exe`：電腦版 `hongsheng-shipping.exe`
- `hongsheng-handheld-apk`：手機 App

## 在 Windows 11 自己編譯

只需要做一次的準備：

1. 安裝 Rust：到 <https://rustup.rs> 下載 `rustup-init.exe` 執行，照預設選項安裝。過程中會提示安裝 Visual Studio C++ Build Tools，請勾選「使用 C++ 的桌面開發」。
2. 開新的命令提示字元，安裝 Tauri 編譯工具：
   ```
   cargo install tauri-cli --version "^2" --locked
   ```

編譯：

```
cd 專案資料夾\app
cargo tauri build
```

第一次編譯約 5–10 分鐘。完成後：

- `target\release\hongsheng-shipping.exe` ← **這個就是程式本體**，可直接複製使用
- `target\release\bundle\nsis\` 裡另有安裝檔（不需要可以忽略）

開發時用 `cargo tauri dev` 可以邊改邊看。核心邏輯的測試：在專案根目錄執行 `cargo test -p shipping_core`。

## 放置方式（建議）

建一個資料夾，例如 `D:\出貨系統\`，把 exe 放進去。第一次執行會在旁邊自動建立 `data\`：

```
D:\出貨系統\
  hongsheng-shipping.exe
  data\
    shipping.db        ← 所有資料
    backup\            ← 每日自動備份
```

不要放在 `C:\Program Files`（沒有寫入權限，程式會改存到 `%APPDATA%\HongshengShipping`）。換電腦時整個資料夾複製過去即可。之後更新程式只要換掉 exe，`data` 不用動。

## 第一次使用印表機（LQ-310）

程式有兩種列印方式，在「設定」切換：

| 方式 | 適合 | 說明 |
|---|---|---|
| 文字模式（預設） | 印表機有中文字庫 | 程式直接送 ESC/P 指令與 Big5 文字，字最清楚，複寫紙第三聯也看得到 |
| 驅動程式 | 印表機沒有中文字庫 | 經 Windows 驅動以圖形列印，跟一般印文件一樣 |

**先確認印表機有沒有中文字庫**：關機狀態按住 LOAD（或 Tear Off）鍵再開機，會印出自我測試頁，上面有中文字就是有。

**文字模式的準備**

1. Windows 要先裝好 LQ-310 驅動（或內建的「Generic / Text Only」也可以），程式只是借用它的列印佇列。
2. 到「設定」選擇印表機，按「列印對位測試頁」。
3. 測試頁每一行開頭有行號、第一二行是欄位尺標，對照實際紙張調整：
   - 第二頁的第 01 行沒有落在撕線後同樣位置 → 調「每頁行數」（9½×11 吋、行距 30 時是 66）
   - 整體太靠上或靠下 → 調「上留白」
   - 太靠左右、或尺標被切掉 → 調「左邊界」與「每行字數」
   - 中文變亂碼 → 先試著取消「送出中文模式指令」；還是不行就改用驅動程式模式
   - 校正好之後，開一張 30 筆左右的出貨單試印，確認第一張印完剛好停在撕線、第二張從撕線後接著印。「每頁行數」要是偶數（中一刀＝一半）
4. 列印前紙張的撕線要對齊印表機的頁首位置（程式每次開始列印都會把目前位置當作頁首）。

**驅動程式模式的準備**

1. LQ-310 的「列印喜好設定」→「自訂紙張」建立「中一刀」，並在「進階」把紙張大小設為中一刀、列印方向為直印（目前用的是寬 21 cm、長 14 cm）。
2. 程式「設定」頁的「驅動程式紙張寬／長」填同樣的數字（預設 21 × 14 公分）。「每行字數」建議 79（中一刀 21 cm 寬可以放到 80）；左右位置可再用「左邊界」與「每行字數」微調。程式每次列印都會送出剛好這個大小的頁面，所以不會轉向、也不會縮小。
3. 程式按列印時會出現 Windows 列印對話框，確認印表機是 LQ-310、紙張是中一刀後列印。

之前遇到超過 13 筆就變橫式的問題，原因是程式送出 9½×11 吋的直式頁面，但驅動程式的紙張是 21×14 cm 的橫長形，WebView2 只好把紙轉向。現在頁面一律跟中一刀同尺寸，這個問題就不會再發生。之後如果改了中一刀的尺寸，記得設定頁也要一起改。

## 單據規則

- 單號：出貨單 `S年月-流水號`、退貨折讓 `A年月-流水號`、對帳單 `T年月-流水號`，依單據日期的月份編號
- 金額：每列「數量 × 單價」四捨五入到元；稅金依客戶稅別（外加 5%／內含 5%／免稅）計算
- 品名或客戶名稱裡有 Big5 沒有的字（例如簡體字、罕用字），存檔時會提醒，列印會變成「？」

## 專案結構

```
core/   資料庫、計價、分頁排版、ESC/P 產生（純 Rust，有單元測試）
app/    Tauri 程式本體、Windows 列印、備份
ui/     介面（HTML/CSS/JS，不需要 Node.js）
handheld/web/      手機畫面與同步邏輯（HTML/JS，瀏覽器也能開來測試）
handheld/android/  手機 Android 外殼（WebView、存檔、連線、列印）
.github/workflows/ 自動編譯 exe 與 APK
```

資料庫結構有版本號（`PRAGMA user_version`），之後改版會在 `core/src/db.rs` 的 `migrate()` 自動升級舊資料。
